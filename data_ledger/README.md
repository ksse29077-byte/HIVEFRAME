# Data ledger

Create one metadata record per admitted model, dataset, clip, image, audio file, or adapter. Never commit private data or licensed media binaries.

Required fields:

- record ID and status (`proposed`, `approved`, `blocked`, `retired`);
- asset type and exact artifact ID;
- source URL, acquisition date, and cryptographic digest;
- rights holder and provenance;
- license name/version and preserved source location;
- research, commercial, modification, redistribution, and output rights;
- attribution and acceptable-use duties;
- consent and personal-data considerations;
- reviewer, decision date, retention/deletion rule;
- dependent checkpoints, adapters, reports, and releases.
